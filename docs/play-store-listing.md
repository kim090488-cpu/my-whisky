### 공유하지 않는 데이터
- 광고주에게 공유 안 함
- 애널리틱스 서드파티에 판매 안 함
- OAuth 공급자(Google, Kakao)와 Anthropic·Supabase·Vercel·Firebase는 "처리 위탁"이며 "공유"에 해당하지 않음 (Play 정책상)

### 보안 관행
- ✅ 데이터가 전송 중에 암호화됨 (HTTPS/TLS)
- ✅ 사용자가 데이터 삭제를 요청할 수 있음 (앱 내 계정 삭제)
- ❌ 이 앱을 사용하기 위해 데이터를 수집할 수 없음 (선택형 데이터 존재)

## 11. 스크린샷 (필수)

Play Console → 스토어 등록정보 → 그래픽

### 필수 자산
| 항목 | 규격 | 필수 |
|---|---|---|
| 앱 아이콘 | 512×512 PNG, 알파 없음 | 필수 |
| 피처 그래픽 | 1024×500 PNG/JPG, 알파 없음 | 필수 |
| 스마트폰 스크린샷 | 최소 2장, 최대 8장, 16:9~9:16 비율, 320~3840px | 필수 (최소 2장) |
| 7" 태블릿 스크린샷 | 최소 1장 권장 | 선택 |
| 10" 태블릿 스크린샷 | 최소 1장 권장 | 선택 |

### 스크린샷 촬영 가이드 (권장 순서 · 8장)
1. **홈 피드** — 다른 사용자의 최근 테이스팅 노트 (소셜성 강조)
2. **위스키 상세** — 라벨 사진 + verdict + 평점 (핵심 콘텐츠)
3. **테이스팅 새 기록** — 5가지 풍미 슬라이더 + 사진 첨부 (기록 UX)
4. **AI 큐레이터 대화** — "셰리 캐스크 추천해줘" 같은 자연어 응답 (차별 기능)
5. **컬렉션 소유/위시리스트** — 병 목록 grid + 총액
6. **바코드 스캔** — 카메라 뷰 with overlay (편의 기능)
7. **랭킹** — 상위 위스키·증류소 리스트 (커뮤니티 지표)
8. **Wrapped** — 개인 연말 정리 카드 (감성 훅)

**촬영 팁**:
- 실기기 스크린샷 (에뮬레이터 X — 상단 상태바 실제 모양 필요)
- 삼성폰 스크린샷 상단 X 툴바는 자르기
- 로그인 상태, 데이터 있는 상태로 촬영
- Play Console에서 자동으로 프레임 추가하지 않으므로 원본 그대로 업로드

## 12. 릴리즈 트랙 (권장 순서)

1. **내부 테스트 (Internal testing)** — 즉시 배포, 최대 100명, 이메일 초대. 첫 AAB 검증.

**첫 배포 권장 흐름**:
- AAB 업로드 → 내부 테스트에 배포 → 본인·지인 폰에 설치 검증 → 이상 없으면 프로덕션으로 승격
